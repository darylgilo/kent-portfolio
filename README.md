# Kent Daryl M. Gilo - Pixel Art Portfolio

A pixel-art styled portfolio website built with Next.js, featuring dark/light mode and a minimalist black and white aesthetic.

## Features

- **Pixel Art Design**: Retro gaming aesthetic with pixel-style fonts and UI elements
- **Dark/Light Mode**: Toggle between themes with smooth transitions
- **Responsive Design**: Fully responsive across all devices
- **Smooth Animations**: Framer Motion powered animations and transitions
- **Skills Showcase**: Displays all professional roles and skills
- **Contact Section**: Easy access to social media and contact information

## Tech Stack

- **Next.js 16**: React framework with App Router
- **TypeScript**: Type-safe development
- **Tailwind CSS**: Utility-first CSS framework
- **next-themes**: Theme management
- **Framer Motion**: Animation library
- **Press Start 2P**: Pixel art font

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Customization

### Update Personal Information

Edit `app/page.tsx` to update:
- Name and title
- Skills and roles
- About section content
- Contact links and social media

### Modify Styling

Edit `app/globals.css` to customize:
- Pixel art effects
- Animation timings
- Color schemes
- Border styles
